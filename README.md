# estrutura-dados-avancada-arvore-binaria-busca
Implementação de uma Árvore Binária de Busca (ABB) em linguagem C, desenvolvida para a disciplina de Estrutura de Dados Avançada. O projeto permite inserção, busca, exibição em ordem, visualização da estrutura da árvore e reinicialização da árvore com liberação de memória.
