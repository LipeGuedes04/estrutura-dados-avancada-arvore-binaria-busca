# Árvore Binária de Busca

Trabalho desenvolvido para a disciplina de Estrutura de Dados Avançada.

## Sobre o projeto

Este programa implementa uma Árvore Binária de Busca (ABB) utilizando a linguagem C. O usuário pode inserir valores, realizar buscas, visualizar os elementos em ordem crescente e exibir a estrutura da árvore.

## Funcionalidades

* Inserção de elementos
* Busca de valores
* Exibição em ordem
* Exibição da árvore
* Reinicialização da árvore
* Liberação de memória

## Estrutura utilizada

Cada nó da árvore possui:

* Um valor inteiro
* Um ponteiro para o filho da esquerda
* Um ponteiro para o filho da direita

## Como executar

Compilar:

```bash
gcc arvore.c -o arvore
```

Executar:

```bash
./arvore
```

## Menu do programa

```text
1 - Inserir elemento
2 - Buscar elemento
3 - Exibir em ordem
4 - Exibir árvore
5 - Reiniciar árvore
0 - Sair
```
